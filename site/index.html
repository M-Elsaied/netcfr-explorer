How networks of self-interested agents learn to play equilibrium

Every agent sits on a node and plays a separate zero-sum poker contest with each neighbor, but it must choose one stance (check or bet) for all of its contests at once. Agents update from local, counterfactual information only. These pages show how close the network gets to equilibrium, how fast, and what it costs in communication.

Reading the numbers

The game

Each agent draws a private card. On every edge the two endpoints ante; an agent that bets raises the stake on all its edges; a checking agent facing a bet folds or calls on that edge. Every edge is zero-sum, so the whole network is too.

Exploitability

NashConv sums, over agents, how much each could gain by deviating alone. It is exactly 0 at a Nash equilibrium and is computed exactly here, never estimated.

Average vs. current

No-regret learners guarantee that their time-averaged play converges. The current policy — what a deployed agent actually plays — may keep cycling. Both are shown throughout.

How you round matters as much as how many bits

Same instance, same q bits per probability, three ways to round. Deterministic rounding biases every payoff an agent perceives and learning stalls; unbiased stochastic rounding and error feedback let the bias cancel out over time.

Stochastic rounding sends ⌊xL + U⌋/L with fresh uniform U, so each received value is correct on average; the shaded band spans five random seeds. Error feedback adds the previous rounding residual before rounding, which needs one stored number per message at the sender. Values are NashConv per agent of the average profile after the final iteration.
